# Network Operations Lab

Painel didático de observabilidade com uma topologia e eventos totalmente simulados. A interface demonstra como resumir disponibilidade, latência e pontos de atenção sem realizar conexões ou varreduras.

## Funcionalidades

- Filtro de equipamentos simulados por estado.
- Visão resumida de disponibilidade e alertas.
- Detalhes de cada dispositivo usando dados locais fictícios.

## Conteúdos relacionados

Introdução a Redes, Infraestrutura de Redes, Sistemas Operacionais, Tecnologias de Hardware, Sistema Operacional de Rede e Gerência de Redes.

## Segurança e execução

Abra `index.html` em um navegador. O projeto não consulta, escaneia nem altera redes reais.
